# unisc-harvard — BibLaTeX style for UniSC Harvard referencing style
© 2026 ade ishs

This package is a BibLaTeX style to format reference lists in the
[Harvard style of University of the Sunshine Coast, Australia
(UniSC)](https://libguides.usc.edu.au/harvard). The package contains
a citation style (unisc-harvard.cbx) and a references section style
(unisc-harvard.bbx).

The current version implemented by this package is the 8th edition
(June 2022 update).

The initial version of this package was vibe-coded with Microsoft 365
Copilot as I did not know how to write a BibLaTeX style. The
particular course I was studying that made me develop this did not
provide allowance for other referencing styles (others did), and I
could not find an existing package that conformed to the prescribed
style. It also seemed that within the course cohort I was doing, I was
the only student using LaTeX, which probably was not a surprise since
I was studying business.
